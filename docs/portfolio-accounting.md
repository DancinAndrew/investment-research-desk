# 手動完整帳務與可重算績效

2026-10-11授權A4–A6；資料與實操完成分列於階段交付。沿用同一私人D1、身份隔離、整帳CAS及歷史trigger，schema_version仍1；finance與imports可省略，舊備份不改。沒有即時行情、券商連線或新外部API。

## 資料與核對流程

交易由既有records保存原理由、報告版、來源、日期與費用；成交日扣／加同幣別現金。finance.events新增DEPOSIT/WITHDRAWAL（外部流）、DIVIDEND/INTEREST（內部收入）、FEE/TAX（其他實付）、SPLIT（每舊股換ratio新股）、FX（实际付出与取得两币金额）。費用不重扣，股息需明確淨入帳或另記稅；同日拆股先於成交。這是一組合併帳本，不支援融資、交割延期、實物轉入、分拆公司或併購自動帳務。每日收盤歷史現金不足保留gap，不能把晚到入金當早期已有資金。

prices以ticker/currency/date唯一；fx以date/currency/base_currency唯一，rate表示1來源幣別可換多少計算幣別。估值僅採精確日期，不假設過去匯率／價格可沿用。不同幣別先列現金及持股，指定日缺任何必要價格／匯率或歷史資金缺口時total_value=null。舊quotes仍供交易回顧手動價格，不自動轉成finance歷史日價。移除拆股仍要全帳重播，會造成超賣即拒絕保存。

valuation是含股票與現金、全部費稅後的同幣別整體資產，不是只有股票市值。close作為起／訖；before_flow/after_flow綁當日外部flow_id。每日多筆外部現金流以order唯一排序，前後估值差須等於當筆實際換算流量。修改外部流日期會使不吻合的估值驗證失敗；移除外部流前須先核對其估值。

## 報酬方法

使用者先明確確認歷史完整。TWR顯示期間報酬，每次外部入出金前切一子期間，各段報酬因子連乘；缺任一前後估值或差額不符留null並列需要補的項目。起日close已含起日流量，計算流量範圍start < date <= end；終日close為當日全部外部流量後。正數期初及每次流量後價值是乘積法的分母前提。

MWR以actual/365年化XIRR，從投資者角度期初資產與存入為負、取出及期末價值為正。同日流量先相加。使用log(1+r)求解並對指數縮放，避免長期間溢出。僅一個符號變化才求單一值；多次符號變化保留不確定，可能不只有一個可解值，不顯示任意猜根。求解界限log(1+r)=[-20,20]、200次二分；界外無穩定解時留空。股息與買賣留在帳內不算外部流。

基準資料需同起訖日、同計算幣別。benchmark_kind=total_return才計TWR與基準的百分點差；price指數未含股息只列其本身報酬，不冒充同口徑超額。MWR年化不和期間基準直接相減。基準名字由使用者填，沒有自動市場資料。

方法參考：[Portfolio Performance TWR](https://help.portfolio-performance.info/en/concepts/performance/time-weighted/)、[MWR](https://help.portfolio-performance.info/en/concepts/performance/money-weighted/)。本實作採逐外部流邊界估值，不假稱每日近似法或稅務申報。

## 手算核對

買10股×100、費用10：成本1010。2:1拆股後20股成本仍1010；賣15×60、費用5：收入895，售出成本757.5，實現137.5；餘5股成本252.5。拆股前價格不能直接估值拆股後股數。

期初外部入金2000USD，買股1010，股息20、稅3、其他費2、換100USD得3200TWD：現金905USD及3200TWD。當日10股×110=1100USD，當日TWD/USD=1/32：總價值905+100+1100=2105USD。

一整年起100終121、基準100到118：TWR21%、年化MWR21%、基準18%、差3百分點。中間入100，流量前110、後210、終231：TWR=(110/100)×(231/210)−1=21%，MWR按日期另求。兩年100到121為期間21%、年化約10%（依實際天數）；兩種期間不可混叫21%。

## CSV與復原

每行一成交。UTF-8 BOM、逗號／分號／Tab、雙引號／換行／CRLF可解析；日期格式與小數千分位明確選擇。缺費用不能自動零，須使用者確認；缺當時理由保存「未記錄」。預覽不寫入，列格式錯誤／相同ID重複／ID衝突／可能同日同價重複，後者需明確確認為不同成交。穩定文件/列ID，重匯同檔不重複；全state hash綁preview，資料已改就需再預覽。套用以整帳重播（含split）與CAS，不部分寫入。

imports保留批次source_hash、record_ids、每筆完整正規化record hash及applied/undone。撤銷只移除本批未修改資料；有回顧、後續賣出依賴或修改即阻擋。CSV保存全部19個成交欄位，試算表formula與原leading apostrophe先轉義，選本工作台匯出檔可精確反向還原。下載與readonly全文共用資料；完整JSON另含research/finance/imports。交易與資金清空保留research，完整備份／歷史可回復全部區域。正式帳本保持零fixture。

## 回顧結果

按實際有效成交、成交日期與理由／風險／回顧文字篩選，每筆只取最新日期回顧（同日最後保存）計數。尚未回顧、未寫預期及失效條件明示；支持／削弱／混合是使用者判斷，不當作勝率或預測正確率。可回到原版報告及全部回顧；空資料只給空狀態。
