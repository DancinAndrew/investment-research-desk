# 使用流程：在公司頁完成跨季閱讀

這是待開發設計，不是目前站點已提供的畫面。

## 入口與閱讀順序

公司清單 → 既有公司概覽 → **財報與法說** → 選擇資料截止／季別 → 看覆蓋與重要變化 → 展開原句／財務事實 → 保存自己的核對結果。公司概覽仍以公司生意和目前判斷為首，不讓新的工具名稱取代內容。

新增一個公司內入口，內分三頁：

| 頁面 | 首屏內容 | 進一步展開 |
|---|---|---|
| 財務 | 八季營收、毛利、營益、EPS及必要現金／CapEx；單位、財季、發布日可見 | 原表、會計口徑、分部、衍生公式、修訂前後 |
| 法說 | 本季主要說法、帶期限的目標、未解問題；準備稿與Q&A可切换 | 講者角色、完整上下文定位、官方文字／ASR標示、原音時間 |
| 變化 | 相比上季哪些數字、目標與解釋變了；最強反方與三個追蹤問題 | 相同主題八季時間線、目標對實績、反方來源、研究者判讀 |

首屏只顯示會改變判斷的三至五項；五類主題是篩選，不是五個新主選單。coverage 摘要直接寫「8季：8份財報已核；法說文字6份已核、2份待核」等實際狀態，不用一個泛稱完成的綠勾。完整覆蓋表可展開。範例數字只是介面示意，不是本輪結果。

擬定 URL：`?workspace=company&company=NVDA&companyTab=financials&financialView=changes&period=<period_id>&asOf=<cutoff>&claim=<claim_id>`。沿用公司列表搜尋、產業、市場、收藏參數與back/reload行為；舊 `companyTab=viewpoints` 等連結不變。日期模式由明確控制選擇，網址參數不能繞過period／as-of驗證。

## 一條變化怎樣呈現

先顯示簡短判讀，例如「驗證時間延後；是否影響本年度交付仍未知」，旁邊列已審／待核。展开後依序：

1. **當時**：原句、講者、說話日、原始期限／KPI、適用產品與地區。
2. **現在**：新原句與日期；時間、數值、範圍、條件究竟哪項改变。
3. **實績**：可比的已公布數字；沒有對應資料就寫「未揭露，無法判定」。
4. **解釋**：管理層理由和研究者推論分栏；另一個能解釋相同現象的假說。
5. **接下來核對**：哪份資料、哪個日期或事件、何種結果支持／削弱判斷。

原文和中文轉述並列可切換，翻譯不標成原文。引用按鈕開原始文件及頁／段／時間，不只回到來源首頁。短引與附近上下文應在同個抽屜閱讀；無全文展示權時顯示短引、自己寫的摘要和合法原網址，不在前端暗藏全文。

「語氣變化」只列為候選觀察。沒有相同主題、時間與口徑的前後說法時，不產生惡化／改善判定。沒被新一季提到的主題是「本期未找到提及」，不是撤回承諾。

## 人工接受與月度流程

按「記錄重新核對」先看到原決定的固定report SHA、當時資料包與新證據。研究者可選維持、信心提高、信心降低、撤回、尚待資料，並必填理由／引用與最強反方。**頁面瀏覽、模型新claim、股價變動都不能自動更改原決定。** 第一階段先透過原報告附錄與既有人工check完成連結；新的結構化保存域在P1才開發。

月度thesis畫面在同公司「變化」頁內啟動，四列需求、營運、競爭、價格，各顯示基線、新證據、支持、反證、未知。價格列不自动改基本面列。新版本接受後保留原版。

每月研究回顧接在既有「回顧」入口，顯示當時可知／後來知道的資料、改判原因、遺漏或過度解讀、研究優先序。下月列五項具體工作，每項有問題、待查來源、完成條件與優先理由；確實只有較少必要工作時顯示「另N項未安排」，不填湊數任務。沒有排程，使用者手動發起。

## 例外狀態與可用性

| 狀態 | 顯示與操作 |
|---|---|
| 未建資料包 | 「尚未整理財報與法說」＋已有完整研究入口；不複製別家公司資料 |
| 八季不齊 | 顯示各季缺項；可對齊的子集可比較，但標明實際N季，不稱完整八季 |
| 本期尚未發布 | 財季已結束、結果未發布分開；不插入估计值冒充actual |
| 文字有、音訊無／相反 | 分別顯示資料型態；沒有音訊不宣稱核過聲音；ASR未覆核不判目標成敗 |
| 不可比 | 指出幣別、會計、分部重編、產品範圍或時間差；可另看原表 |
| 修訂 | 顯示原版與修訂版、各自可用時間；舊決策連結不換新hash |
| API/下載錯誤 | 最近有效資料＋日期與本次失敗原因，保留重試；不清空為0、不假裝更新成功 |
| 載入中／切公司 | 顯示狀態，取消前公司請求，舊回應不可覆蓋新頁 |
| 引用找不到／hash不合 | 停止該列結論與引用，列「來源待重新核對」；不可用模糊匹配換成別句 |
| 尚未覆核 | 草稿標籤與原始證據；不得冒稱正式研究 |

手機預設一次兩季比較，提供左右選期；桌面可看八季寬表。文字／圖表皆有單位、負值、實際／估計與可讀表格替代。鍵盤可聚焦引用、關閉抽屜回原位置；狀態用文字與 `aria-live`，不只靠紅綠。技術hash、jobs、token用量放「檢查紀錄」，不進讀者主流程。
