# 介面契約 v2

採用已審核的 Interface Design 設計準則。意圖：先閱讀公司生意，再沿關係與來源查證；交易是本人手動帳本。

層次：主導覽研究／交易／資料，各兩項子功能；正文為閱讀焦點，關係圖為探索焦點，右欄是證據。沒有同級卡片牆。字級 26/21/17/14/12；控制區 4/8/12/16px，閱讀段落 20/28/36px。白紙、深灰綠字、一個克制綠色重點；無漸層、陰影、圓膠囊導航。表單採緊湊原生控制，手機觸控最小44px。鍵盤 focus 保持可見。

關係图使用原15節點/20關係，不修改原索引、金額、結論或來源。AI雲端、政策監管、零售物流是閱讀篩選分組，不是新增研究判定。三方關係共有標籤，不能讀成任意兩者均有雙邊合約。SVG支援拖移、縮放、鍵盤方向、節點/連線選取、等效原生選單；手機詳細欄位位於圖下方。

Markdown在建置時由既有Pandoc解析成標準AST。前端依明確節點schema輸出HTML，原始HTML/TeX不執行，連結僅http(s)、已登錄檔案與本頁錨點。原文不可更改；MathML由Pandoc產生；已註冊純文字也保留，未產生AST時只顯示安全文字。方法頁七步不使用額外列表標號，完整手冊降一階標題。

帳本GET傳回不可反推身份的owner_scope與環境標籤，PUT須與當前身份/來源環境同scope且CAS版本相同。每次重新进入帳本及視窗重新聚焦核對身份，載入失敗清空舊畫面/表單/歷史。環境區分正式私人D1與本機隔離SQLite。清空操作先下載備份，再存空白records/quotes/reviews，D1觸發器保留前版；不刪研究IndexedDB、X資料、來源或歷史研究。

手機320px實測後修正：500×500世界視窗、預設1.6倍近景；選取節點/關係自動置中。完整登錄數與可操作原生選單仍顯示。桌面保留全範圍視圖，手機可reset、縮小、拖移探索全圖。
